# MenuFit

Code-first repository for the new MenuFit implementation.

## Structure

- `src/backend/`
- `src/admin-web/`
- `src/ios-user-app/`
- `src/shared/`
- `infrastructure/`
- `.github/` (Copilot instructions and agents)
- `.copilot-tracking/` (plans, details, changes tracking)
- `.agents/skills/` (Codex skill definitions)

Planning artifacts (blueprints/workitems) are kept local and are not versioned in this repository.
