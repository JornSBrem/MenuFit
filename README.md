# V3 Workspace

- `v3/docs/APP_V3_MEDALLION_BLUEPRINT.md`
  - Hoofdblueprint voor product, architectuur, data model, UI en roadmap.
- `v3/docs/PG_ENDPOINT_CONTRACT.md`
  - Vastgelegde Project Gezond endpoint-contracten.
- `v3/docs/REFACTOR_SIMPLIFICATION_PLAN.md`

- `v3/docs/MATCHING_SHARED_CORE_DESIGN.md`

- `v3/src/backend/`
  - Nieuwe backend codebase (te bouwen).
- `v3/src/admin-web/`
  - Beheerfrontend codebase (te bouwen).
- `v3/src/ios-user-app/`
  - Native iOS gebruikersapp (Swift/SwiftUI, te bouwen).
- `v3/src/shared/`
  - Shared contracts/types/logica tussen backend/admin.
- `v3/infrastructure/`
  - Infra/deploy artifacts voor online backend en dev omgevingen.
