# Copilot Tracking

Use this folder to run structured feature delivery.

## Folders

- `plans/`: implementation plans (task checklists).
- `details/`: optional deep-dive notes per task/phase.
- `changes/`: release-style change logs tied to a plan.
- `templates/`: reusable templates.

## Minimal Flow

1. Copy `templates/implementation-plan.template.md` to `plans/`.
2. Execute tasks in order.
3. Update a matching file in `changes/` after each completed task.
